What it does

Builds a local vector knowledge base from telecom / packet-core documents and answers in RU/EN without sending corpus data to the cloud after models are pulled.

Pipeline

Ingest PDF/MD → chunk → embed (all-MiniLM-L6-v2) → Chroma → retrieve → Qwen2.5:7B via Ollama → answer with sources.

  • Console UI for KB build and Q&A
  • Synthetic sample docs in public repo
  • Typical answers often 5–40 s on NVIDIA
